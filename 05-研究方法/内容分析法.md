# 内容分析法（Content Analysis）

> **一句话定义**：把非结构化文本（纪要、公告、舆情）转成可统计的结构化数据——让"话"变成"数"。

## 是什么

传播学经典方法，现在与 NLP 结合后威力倍增。核心动作：定义编码体系（怎么分类）→ 对文本按体系编码 → 频次与共现统计 → 解读模式。

## 操作流程

1. **确定分析单元**：词 / 句 / 主题 / 篇章
2. **构建编码体系**：分类维度 + 明确判定规则（两人生效：随机抽 10% 双人编码，一致性 >80% 体系才可用）
3. **编码计数**：各维度频次、趋势、共现关系
4. **统计解读**：频次变化 = 注意力变化；措辞情感 = 态度变化

## 典型指标

- **词频趋势**：年报/电话会中"降本"提及次数逐年上升 → 管理层注意力转向
- **情感极性**：措辞从"挑战与机遇并存"到"压力前所未有"的极性迁移
- **主题共现**："机器人"与"订单"共现率上升 vs 与"研发"共现——从讲故事阶段进入兑现阶段的信号
- **回避度**：问答环节对某问题的回避/复读次数——不愿谈的才是关键

## 研究工作中的应用

- **管理层话风追踪**：连续 8 个季度电话会文本编码——"需求"词频下降+"库存"词频上升 → 领先于报表的景气度信号
- **产业纪要批量处理**：几十份专家纪要按编码体系（环节/公司/技术路线/态度）结构化入库 → 统计"看多丝杠国产化的专家占比及变化"——把散落印象变成可跟踪序列
- **政策文本量化**：政策文件中"支持/规范/清理"的措辞密度与位置（标题级 = 强信号）——政策温度计

## 局限与陷阱

- 编码体系质量决定一切——分类不 MECE 则统计无意义
- 频次 ≠ 重要性：说得多可能是重要，也可能是心虚（重复保证）
- 文本可被策略性生成（话术培训、预期管理）——文本信号要与行为数据（资本开支、回购）交叉验证
