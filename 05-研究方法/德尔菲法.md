# 德尔菲法（Delphi Method）

> **一句话定义**：多轮匿名专家问卷 + 反馈收敛——不面对面，用结构化流程榨出群体判断的真值。

## 是什么

兰德公司发明。对抗面对面研讨的三大病灶：权威压制（谁职级高听谁的）、从众压力（当面不敢唱反调）、话语权垄断（能说的赢过能想的）。德尔菲的核心设计是**匿名 + 迭代 + 统计反馈**。

## 操作流程

1. **第一轮**：开放问卷——专家独立给出预测/判断及理由
2. **汇总反馈**：主持人统计中位数与四分位区间，匿名返还全体（"50% 的专家认为 2028 年出货 X 万台，区间 [A,B]"）
3. **第二轮**：专家看到群体分布后修订自己的判断（可坚持可改变，偏离中位数者需给理由）
4. **迭代 2-4 轮**直到收敛（四分位距收窄）
5. **输出**：中位数预测 + 区间 + 主要分歧点及各方论据

## 关键设计

- **匿名**：判断与身份隔离，职级不参与
- **理由伴随**：每轮收集论据——德尔菲的副产物是结构化的"论据地图"
- **主持人的中立性**：只统计不引导

## 研究工作中的应用

- **量产节奏预测**：人形机器人 2028 年出货量——找产业链 8-12 位专家（整机/零部件/设备商/学者），德尔菲三轮 → 比任何单一专家或卖方一致预期信息含量更高
- **分歧定位**：收敛失败（区间不再收窄）本身就是结论——分歧的结构（哪个环节的专家更乐观）揭示不确定性的来源
- **组织内部预测**：下季度板块表现，团队匿名德尔菲——对抗"领导先定调"的会议文化

## 局限与陷阱

- 专家质量决定上限——德尔菲无法把无知平均成智慧
- 可能收敛到错误共识（群体思维的匿名版）——保留极端意见的论据记录，不许简单平均
- 轮次耗时（2-4 周常见），快节奏场景用"闪电版"（一轮+反馈）
