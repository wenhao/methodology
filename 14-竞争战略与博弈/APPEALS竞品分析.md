# $APPEALS 竞品分析（IBM / 华为 IPD）

> **一句话定义**：把客户购买判断拆成 8 个价值要素（$价格/可获得性/包装/性能/易用性/保障/生命周期成本/社会接受度），加权打分与竞品逐维对标——用雷达图找出差距与差异化机会。

## 是什么

IBM 原创、华为 1998 年起引入 IPD（集成产品开发）后发扬光大，成为中国企业产品管理标配。核心逻辑：

- **客户购买的不是产品，而是多维价值组合**：不同客户对 8 维权重不同（政企客户重保障合规，消费电子用户重易用性能）——产品竞争力 = Σ(各维得分 × 客户权重)
- **8 个维度像 8 张 X 光片**：强制跳出"只看性能"的工程师思维，全面扫描客户价值
- **竞品对标可量化**：把"我们和友商比怎么样"从口水战变成同框架打分对比
- **跨职能统一语言**：市场、研发、制造、服务对"什么是好产品"坐在同一张表前谈

**八大价值要素**：

| 要素 | 关注点 |
|---|---|
| **$ 价格 Price** | 采购价、付款条件、折扣、入门门槛 |
| **A 可获得性 Availability** | 渠道覆盖、交付周期、现货能力、定制弹性 |
| **P 包装 Packaging** | 外观、工艺质感、视觉呈现（广义含交付体验与文档） |
| **P 性能 Performance** | 核心功能、速度、稳定性、技术指标 |
| **E 易用性 Ease of Use** | 部署、学习成本、操作、维护排障 |
| **A 保障 Assurances** | 可靠性、安全性、质保、售后、SLA |
| **L 生命周期成本 Life Cycle Cost** | 运维、能耗、升级、耗材、培训等 TCO |
| **S 社会接受度 Social Acceptance** | 品牌口碑、认证资质、合规、知识产权 |

操作三件套：权重分配（来自真实客户调研，按细分市场分别设）、评分（1-5 分制，我方 vs 竞品 vs 客户期望三方）、雷达图差距分析（短板补齐 / 优势差异化 / 明确放弃）。

## 核心操作

1. **锁定细分市场与竞品**：先明确"给谁对标、对标谁"——不同细分权重不同，混用即失真
2. **客户调研定权重**：权重来自客户口中的"最在意什么"，不是产品团队的偏好
3. **三方打分**：我方 / 2-3 家主要竞品 / 客户期望值，每分配证据
4. **雷达图找差距**：低于期望的维度是必须补的短板；高于竞品且客户重权的维度是差异化卖点；客户不在乎的维度是降本空间
5. **转需求优先级**：差距分析输出为产品定义与路线图的优先级排序（与决策矩阵联动）

## 工作应用

- **产品型公司的竞争力解剖**：替代"产品竞争力强"的空话——8 维打分表让竞争力可拆解、可跟踪；重仓调研时逐维验证（问客户：价格 vs 交付 vs 服务你更在意哪个）
- **差异化溢价的证据链**：差异化定价能否持续的判据是客户重权维度上的真实领先——性能接近但服务/保障维度分差大的公司，溢价有支撑；反之是"伪差异化"
- **B 端 vs C 端公司的估值差异解释**：B 端权重集中在保障与生命周期成本（切换成本高→收入黏性→估值溢价），C 端集中在性能与易用（易切换→竞争烈度高）——8 维权重结构本身就解释商业模式质量
- **新进入者的突破口预判**：在位者"性能过剩、保障不足"的维度是 challenger 的切口（与颠覆式创新的低端切入联动）

## 局限与陷阱

- 权重调研成本高且会漂移：客户说的与做的可能不一致——用输赢访谈（win/loss）与流失客户访谈交叉验证
- 维度是快消/硬件时代的框架：软件与服务业务的"包装""生命周期成本"内涵要重新定义后使用，生搬硬套产生伪精确
- 静态对标：竞品的下一代产品不在表里——结合对手路线图做前瞻版
- 打分主观性同 CPM：必须配证据与多人大幅校准，否则沦为精致的拍脑袋
