## 使用方式

1. **按问题找方法**：遇到问题先问它属于哪类（判断不清→01；问题模糊→02；分析行业/公司→03；要拍板→04；做研究→05；估值定价→06；多人交付→11；谈合作/争取资源→12；数据可信度存疑→13；竞争格局与对手推演→14）
2. **场景速查**：
   - 写深度报告 → 七步分析法 + 假设驱动 + 金字塔原理 + PE Band + SOTP
   - 板块性价比排序 → PS/PEG + 决策矩阵 + 基准比率 + 幸存者偏差（样本审查）
   - 重仓决策 → 期望值 + 风险预算 + 事前验尸 + 红队检验 + 蒙特卡洛（区间概率化）
   - 复盘 → AAR + 概率思维（事前记录）+ 刻意练习 + 回归效应（归因审慎）
   - 跨团队项目 → RACI + 关键路径 + 风险管理矩阵 + 利益相关方分析
   - 数据结论质检 → 相关性与因果性 + 统计功效 + 辛普森悖论 + 过拟合与样本外验证 + 基础比率谬误
   - 季报解读 → 时间序列与季节调整 + 回归效应（归因审慎）+ 幸存者偏差
   - 竞争格局分析 → 波特五力 + 战略群组 + 对手画像四诊断 + 竞争态势矩阵 CPM
   - 供给行为/价格战推演 → 博弈论与竞争互动 + 战争推演 + 对手画像四诊断
   - 标的护城河与转型成色 → VRIO + 核心竞争力 + 动态能力 + 超级竞争（优势半衰期）
   - 新赛道/新叙事评估 → 颠覆式创新 + 蓝海战略 + 品类战略 + 基础比率（兑现率校准）
   - 持仓风险监控 → 早期预警分析 + 竞争情报循环 + 风险管理矩阵
3. **每条方法论的统一结构**：一句话定义 / 是什么 / 操作步骤 / 工作应用 / 局限与陷阱——局限部分与正文同等重要，误用比不用更糟
