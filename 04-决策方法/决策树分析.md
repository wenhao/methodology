# 决策树分析（Decision Tree Analysis）

> **一句话定义**：把多阶段决策画成树——决策节点（你选）与机会节点（概率分支）交替，逐层回推最优路径。

## 是什么

决策分析的图形化工具，处理**序贯决策**（今天的决定影响明天的选项）。与 EV 的区别：EV 算单一决策，决策树处理多阶段、可条件调整的决策链。

## 两类节点

- **决策节点（□ 方形）**：你可以选的分支——选期望值最大的
- **机会节点（○ 圆形）**：概率分支——计算各分支概率加权值

**回推法（folding back）**：从树梢（最终各分支收益）逐层向上算期望值，在每个决策节点选最优，最终得到第一阶段的最优选择及其完整条件策略。

## 研究工作中的应用

- **建仓节奏决策**：现在建仓 vs 等定点落地再建仓——
  - 现在建仓：定点兑现（60%）+25% / 不兑现（40%）−15% → EV=+9%
  - 等落地：错过涨幅（兑现时只赚 +8%）但躲过回撤（−5%）→ EV≈+2.8%
  - 决策树的附加价值：把"分批建仓"作为第三分支显式比较
- **跟踪决策的预设**：报告里的"若 X 则 Y"条件策略本质是决策树文字化——把未来可能的分岔与应对提前画出来，避免临场情绪决策
- **多情景假设管理**：情景规划（乐观/中性/悲观）+ 决策树组合——情景是机会节点，政策应对是决策节点

## 局限与陷阱

- 分支与概率主观估计误差逐层**复利放大**——超过 3 层的树精度可疑，常用"两阶段树+滚动更新"替代长树
- 画树强迫显式化假设（这恰恰是价值），但也会制造"虚假的完备感"——关键分支遗漏仍可能
- 不处理竞争对手的主动反应（博弈）——需要博弈论的引入
