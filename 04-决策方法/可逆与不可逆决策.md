# 可逆与不可逆决策（Type 1 / Type 2 Decisions）

> **一句话定义**：可逆决策（双向门）要快，不可逆决策（单向门）要慢——用错节奏是最大的决策浪费。

## 是什么

贝佐斯的决策分类：**Type 2 双向门**——走进去发现不对还能退出来（大多经营决策）；**Type 1 单向门**——进去就回不了头（卖公司、巨额沉没投资、品牌定位、关键人事）。两类决策需要完全不同的流程：

| | Type 1 单向门 | Type 2 双向门 |
|---|---|---|
| 节奏 | 慢：数据、论证、多方意见 | 快：70% 信息即行动 |
| 流程 | 正式评审+事前验尸+过夜冷静 | 一人或小团队即可拍板 |
| 容错 | 低——设计逃生预案 | 高——错了回来改 |

**常见病**：把 Type 2 当 Type 1 决策（层层审批，机会在会议中流失），或把 Type 1 当 Type 2（拍脑袋上马，不可逆地烧掉核心资源）。

## 判断问题

三个快速测试：
1. 撤销成本是多少？（资金/声誉/时间）
2. 撤销需要多少方同意？
3. 期间锁定的资源是否致命？

撤销成本 ≈ 0 → Type 2 快走；撤销 = 出血 → Type 1 慢走。

## 研究工作中的应用

- **研究节奏分配**：跟踪标的的日常调仓观点（Type 2，快速迭代、错了就改）vs 核心仓位布局与年度主线判断（Type 1，深度论证+事前验尸）
- **职业资源投向**：深耕哪个板块是 Type 1（能力圈建设不可逆时间成本极高）——值得花一个月论证；用哪个工具写报告是 Type 2——两天试错
- **给"慢决策"装截止阀**：Type 1 不等于无限拖延——设决策截止日，信息永远到不了 100%

## 局限与陷阱

- 可逆性本身在变：很多双向门有隐形时效（机会窗口关闭后双向变单向）
- 组织倾向于把一切包装成 Type 2 求快，或 Type 1 逃责——分类判断要显式写下来
