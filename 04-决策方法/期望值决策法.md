# 期望值决策法（Expected Value / EV）

> **一句话定义**：EV = Σ(每种结果的概率 × 收益)——可重复的决策选期望值最高者，而不是最可能赢者。

## 是什么

概率决策的数学基础，巴菲特的表述："用亏损的概率乘以可能亏损的数量，再用盈利的概率乘以可能盈利的数量，比较两者。"**赔率思维**：30% 胜率的赌局，若赢 5 倍输 1 倍，EV = 0.3×5 − 0.7×1 = +0.8——值得下注，尽管大概率会输这一次。

## 操作步骤

1. 列出所有结果分支（树状展开，多阶段决策用决策树）
2. 每分支估两个数：概率 p、收益 x（**包含本金与时间成本**）
3. 计算 `EV = Σ pᵢxᵢ`
4. 可重复决策 → 选 EV 最高；**单次生存相关决策 → 加约束**（见局限）

## 研究工作中的应用

- **主题投资的仓位逻辑**：人形机器人 0-1 阶段——量产成功（p=40%）标的翻 3 倍 / 不及预期（p=60%）回撤 40% → EV = 0.4×200% − 0.6×40% = +56% → 正 EV 支持配置，但单一标的 p 的估计误差极大 → 分散到一篮子（提高"至少一个成功"的联合概率）
- **事件驱动判断**：政策出台前——出台（p=55%）板块 +8% / 不出台（p=45%）−3% → EV = +3.05%，决定是否提前布局
- **研发投入/项目立项**：AI4SE 项目成败概率 × 各自收益，替代"领导感觉能成"

## 概率估计从哪来（关键）

- **基础比率**：同类事件历史频率（锚）
- **贝叶斯更新**：新增证据修正锚
- **多源独立估计**：专家、数据、模型，分歧本身就是信息

## 局限与陷阱

- **遍历性问题**：单次决策 + 致命损失（破产）时 EV 失效——先保生存再谈 EV（配Kelly与杠铃）
- 概率估计质量决定一切：垃圾进垃圾出——对 p 的敏感度分析必须做
- 忽略方差与路径：相同 EV，波动路径可能触发强平/止损——EV 之外看回撤分布
