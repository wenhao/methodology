# 麦肯锡七步分析法（Seven-Step Problem Solving）

> **一句话定义**：从陈述问题到陈述答案的完整七步流程——咨询业问题解决的标准作业程序（SOP）。

## 七个步骤

1. **陈述问题**：把模糊困扰转成一句清晰的问题陈述（问题的本质是"现状与目标的差距"）
2. **分解问题**（Issue Logic / Logic Tree）：用 MECE 把大问题拆成可分析的子问题
3. **去掉非关键问题**（Kill 批次）：80/20 砍掉不关键的枝干，聚焦驱动因素
4. **制定详细工作计划**：明确子问题、分析方法、数据来源、责任人、时间
5. **进行关键分析**：对保留的关键问题做深度分析（定量优先）
6. **综合调查结果，建构论证**（Pyramid + Storyline）：结论先行，论据支撑
7. **讲述来龙去脉（沟通）**：把分析转成对方能行动的信息

## 核心要诀

- **以假设为导向**（hypothesis-driven）：第 3 步之前先有初步答案假设，分析是为了证实/证伪假设，而不是漫无目的收集数据——第一天就有初稿答案
- **反复迭代而非线性**：新证据出现回到第 2 步调整拆分，SOP 是循环不是流水线
- **解决问题 ≠ 分析问题**：第 6-7 步（综合与沟通）占咨询成败的一半

## 研究工作中的应用

这几乎是深度研究报告的标准骨架：

1. 问题：人形机器人板块当前估值是否合理？
2. 拆解：总量（出货预测）× 格局（环节份额）× 盈利（净利率）× 估值（倍数）
3. 砍掉非关键：估值分歧 90% 来自出货节奏假设——聚焦它，其余用敏感性带过
4. 工作计划：出货预测拆 Tier1 定点进度、产线投资、成本临界点三个子证据
5. 关键分析：对标智能手机/电动车渗透曲线做情景测算
6. 综合：估值区间 = 三情景 × 隐含回报矩阵
7. 沟通：一页结论 + 证伪条件

## 局限与陷阱

- 假设驱动可能滑向确认偏误——证伪证据要给加权机会（搭配灰度认知）
- 对全新的探索性问题（无先验假设可用），更适合先发散研究再套流程
