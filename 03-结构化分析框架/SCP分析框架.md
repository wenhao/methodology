# SCP 分析框架（Structure-Conduct-Performance）

> **一句话定义**：市场结构（S）决定企业行为（C），行为决定经营绩效（P）——产业经济学分析行业的基本因果链。

## 是什么

哈佛学派产业组织理论的核心范式。价值在于把"行业为什么赚钱/不赚钱"拆成可追踪的因果链，并且**双向使用**：正向解释绩效来源，反向推演政策/技术冲击的传导路径。

## 三层结构

- **S 结构**：集中度（CR4/HHI）、进入壁垒、产品差异化、纵向一体化程度、成本结构
- **C 行为**：定价策略、产能决策、研发投入、并购整合、合谋/竞争姿态
- **P 绩效**：利润率、ROE、创新产出、资源配置效率

双向推演：
- **解释**：绩效差异 ← 行为选择 ← 结构约束（毛利率高 ← 稀有提价能力 ← 上游集中度低+技术壁垒高）
- **预测**：外部冲击 → 结构变化 → 行为调整 → 绩效移动（补贴涌入 → 进入壁垒下降 → 扩产潮 → 价格战 → 利润率回归）

## 研究工作中的应用

- **行业剧变的传导推演**：判断扩产潮影响——S 层盯各地开工的产能数字 → C 层推演大厂是否率先降价抢份额 → P 层预判毛利率回归节奏——**比"供给过剩利好龙头"的口号精确一个量级**
- **政策效果评估**：补贴/准入政策落在 S 层（壁垒），还是 C 层（行为诱导），还是直接补 P（利润）——直接补 P 的政策退出后绩效立即回落
- **人形机器人产业推演**：当前结构（整机未定型、零部件标准未统一）→ 行为（零部件厂商广撒网送样、跑马圈地）→ 绩效（研发费用高企、盈利远未到来）→ 结构收敛后的行为与绩效形态预判

## 局限与陷阱

- 芝加哥学派批评：S→C→P 单向因果太机械，P 也反作用于 S（赚钱→吸引进入→集中度变化）——实务中当**循环系统**用，不是单向箭头
- 结构数据滞后（集中度数据常滞后 1-2 年）——用订单/招标/开工等高频行为数据倒推结构变化
