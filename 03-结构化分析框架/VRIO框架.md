# VRIO 框架

> **一句话定义**：用价值/稀缺性/难模仿性/组织利用四层漏斗检验一项资源能否构成持续竞争优势——护城河的司法鉴定。

## 是什么

杰恩·巴尼基于资源基础观（RBV）提出。SWOT 说"这是优势"，VRIO 追问"凭什么这个优势能持续赚钱"。四层逐级筛选，只有全过四关的资源才支撑**持续超额收益**。

## 四层漏斗

1. **V 价值（Value）**：这项资源能否利用机会/抵御威胁？（不值钱 → 竞争劣势/均势）
2. **R 稀缺性（Rarity）**：多少对手拥有？（人人都有 → 只能算平价竞争）
3. **I 难模仿性（Inimitability）**：对手模仿的成本与时间？（容易模仿 → 短暂优势）
4. **O 组织（Organization）**：公司组织能否开发利用它？（有资源不会用 → 潜力浪费）

**模仿壁垒的来源**：路径依赖（历史机缘）、因果模糊（别人看不懂为什么强）、社会复杂性（文化/关系网）——这三者最难模仿，优于单纯的资金与规模壁垒。

## 研究工作中的应用

- **护城河鉴定标准作业**：对公司宣称的每条优势过 VRIO——"客户关系好"：有价值、稀缺性存疑（对手也在维护）、可模仿（挖人）→ 弱护城河；"行星滚柱丝杠量产良率十年积累"：V✓ R✓（国内极少）I✓（工艺 know-how 因果模糊）O✓ → 真护城河
- **估值溢价的合法性审查**：给高 PE 的唯一理由是持续超额 ROE——用 VRIO 检验超额 ROE 的来源，四关全过的才配给溢价
- **尽访谈纲设计**：访谈竞争对手"你最怕它什么"——答案指向 I 层最强的资源

## 与其他框架的关系

- SWOT 找出候选优势 → VRIO 鉴定真伪 → 波特五力解释行业层面 → 三者构成竞争分析三层楼
- 巴菲特护城河语言（品牌、转换成本、网络效应、成本优势、无形资产）是 VRIO 资源类型的通俗版

## 局限与陷阱

- 模仿壁垒会衰减（专利到期、技术扩散），VRIO 需定期重检——护城河是动态的
- 主观判断空间大，"难模仿"的判断本身容易错——配合同行访谈交叉验证
